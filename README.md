# Proyecto Django en entorno virtual

Este proyecto ha sido creado con Python 3.12 y Django en un entorno virtual.

## Estructura básica
- El entorno virtual está en `.venv`.
- El proyecto Django se llama `laboratorio`.

## Comandos útiles

- Activar el entorno virtual:
  ```zsh
  source .venv/bin/activate
  ```
- Ejecutar el servidor de desarrollo:
  ```zsh
  python manage.py runserver
  ```

## Requisitos
- Python 3.12+
- Django

## Notas
Puedes agregar aplicaciones Django usando:
```zsh
python manage.py startapp nombre_app
```
